# portalucn.github.io
Documentación de Sitios UCN
Este repositorio reúne información y descripciones de los distintos sitios institucionales de la Universidad Católica del Norte (UCN). Su objetivo es centralizar y organizar el ecosistema web de la universidad, facilitando la consulta y el acceso de cada plataforma.

Contenido
Listado de páginas oficiales y servicios digitales.

Listado de profesores y contacto de la escuela de ingeniería.

Descripción funcional y propósito de cada sitio

Alcance
Este repositorio es un proyecto independiente con fines informativos y de documentación sobre plataformas públicas de la UCN.
